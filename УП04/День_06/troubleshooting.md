# Диагностика неполадок

В предоставленных материалах нет зафиксированных ошибок, помешавших установке Docker или запуску учебных контейнеров. DNS и HTTPS-проверки прошли, служба Docker имела статус `active (running)`, `hello-world` вывел успешное сообщение, а nginx ответил `HTTP/1.1 200 OK`.

Для возможных ошибок в работе предусмотрены следующие проверки:

`docker: command not found` — проверить `docker --version` и завершение установки.
`Cannot connect to the Docker daemon` — проверить `sudo systemctl status docker --no-pager`.
`permission denied` для `docker.sock` — выполнять команды с `sudo docker`; не менять права сокета.
Ошибка загрузки образа или timeout — проверить интернет, DNS, доступ к Docker Hub и имя образа.
`port is already allocated` — порт 8080 занят; сообщить преподавателю, не останавливать чужие сервисы.
Конфликт имени контейнера — проверить `sudo docker ps -a` и использовать существующий собственный контейнер.
`curl: connection refused` — проверить состояние контейнера, его логи и публикацию порта.
