# Вывод

В ходе практической работы проверено окружение Ubuntu Server 24.04.5 LTS и установлена работоспособность Docker Engine. Служба Docker запущена, команды Docker и Compose доступны. Тестовый контейнер `hello-world` успешно вывел сообщение `Hello from Docker!`. Затем был запущен веб-сервер nginx в контейнере `up04-web`; его доступность проверена HTTP-запросом, получен ответ `200 OK`. Были изучены списки образов и контейнеров, просмотр логов и сведений о контейнере, а также остановка и повторный запуск. Учебный nginx-контейнер после проверки остановлен и удалён.

Docker поможет при развёртывании ИИ-агента тем, что приложение и необходимые для него зависимости можно упаковать в образ. Благодаря этому запуск будет более одинаковым на разных компьютерах и серверах, а настройки окружения будет проще воспроизводить. Создание Dockerfile самого агента относится к следующему занятию.
