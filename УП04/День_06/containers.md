# Работа с образами и контейнерами

## Проверочный контейнер hello-world

Команда `sudo docker run hello-world` запустила тестовый образ. В терминале появилось `Hello from Docker!`; контейнер вывел сообщение об успешной проверке Docker и завершил работу. Поэтому в `docker ps` он не отображается как работающий, но присутствует в `docker ps -a` со статусом `Exited (0)`.

## Веб-сервер nginx

Запуск выполнялся командой:

```bash
sudo docker run -d --name up04-web -p 127.0.0.1:8080:80 nginx:alpine
```

В выводе `sudo docker ps` контейнер `up04-web` имел статус `Up`, образ `nginx:alpine`, а порт был отображён как `127.0.0.1:8080->80/tcp`. 
Проверка `curl -I http://127.0.0.1:8080` вернула `HTTP/1.1 200 OK`; сервер — `nginx/1.31.6`.
Логи просматривались командами `sudo docker logs up04-web` и `sudo docker logs --tail 10 up04-web`; в них видны сообщения запуска nginx и HTTP-запрос.
Контейнер останавливался и запускался повторно командами `sudo docker stop up04-web` и `sudo docker start up04-web`; после повторного запуска HTTP-проверка снова отвечала.

## Ответы на вопросы этапа 5

1. **Образ и контейнер:** образ — шаблон приложения, контейнер — экземпляр образа, созданный для запуска.
2. **Почему hello-world завершился, а nginx работает:** hello-world печатает сообщение и заканчивает выполнение; nginx постоянно обслуживает запросы.
3. **`-d`:** запуск в фоновом (отсоединённом от терминала) режиме.
4. **`--name up04-web`:** назначение контейнеру имени `up04-web` для обращения к нему по имени.
5. **`8080:80`:** порт 8080 хоста перенаправляется на порт 80 контейнера.
6. **`127.0.0.1`:** ограничивает доступ к опубликованному порту самой машиной Ubuntu.
7. **Просмотр логов:** `sudo docker logs up04-web`; последние пять строк — `sudo docker logs --tail 5 up04-web`.
8. **`stop` и `rm`:** `stop` останавливает, сохраняя контейнер; `rm` удаляет остановленный контейнер.

## Команды исследования

```bash
sudo docker ps
sudo docker ps -a
sudo docker images
sudo docker stats --no-stream
sudo docker logs --tail 5 up04-web
```

По приложенным снимкам экрана `docker ps` показывал работающий `up04-web`; `docker ps -a` также показывал завершённые контейнеры `hello-world`. В `docker images` присутствовали образы `nginx:alpine` и `hello-world`. `docker stats --no-stream` выводил разовый снимок использования CPU, памяти, сети и дискового ввода-вывода контейнером.

После проверки учебный контейнер nginx был остановлен и удалён командами `sudo docker stop up04-web` и `sudo docker rm up04-web`; образ можно оставить.
