# Проверка GPU

**Команда lspci и результат:** `lspci | grep -Ei "vga|3d|display"` — обнаружен `VMware SVGA II Adapter` (виртуальный графический адаптер)

**Команда nvidia-smi и результат:** команда `nvidia-smi` не найдена; система предложила установить пакет `nvidia-utils`. Это не подтверждает наличие NVIDIA GPU

**Доступен ли вычислительный GPU:** по представленным результатам доступность вычислительного GPU не подтверждена. В Ubuntu виден виртуальный адаптер VMware

**Требуется ли GPU моему агенту:** нет.

**Обоснование:** агент обращается к GigaChat API через интернет; вычисления модели выполняются на стороне внешнего сервиса. Для запуска данного проекта локальный GPU в виртуальной машине не требуется.
