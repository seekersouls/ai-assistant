# Развёртывание ИИ-агента

**Название агента:** AI-Agent (проект для создания и психологического анализа персонажей)
**Ссылка на GitHub:** https://github.com/seekersouls/ai-assistant/tree/main/%D0%A3%D0%9F01/AI-Agent
**Способ переноса:** клонирование репозитория командой `git clone`
**Путь в Ubuntu:** `/home/pluzhnik/projects/ai-assistant/УП01/AI-Agent`
**Команда запуска:** `python main.py` (при активированном `.venv`)

## Проверки

| Проверка | Ожидалось | Получено | Статус |
|---|---|---|---|
| Запуск | Программа запускается | Скрипт запустился, показал вопросы о персонаже и выбор формата ответа. При продолжении без обязательных данных вывел сообщение о необходимости указать данные персонажа. | Успешно: приложение запускается. |
| Основная функция | Агент выполняет целевую задачу | На запрос с данными персонажа агент сформировал описание персонажа «Телевизор»: возраст, внешний вид, черты характера, сильные и слабые стороны, предысторию. | Успешно |
| Некорректный запрос | Предсказуемая реакция | При отсутствии данных персонажа агент вывел понятное сообщение: «необходимо указать данные персонажа». | Успешно: некорректный ввод обработан предсказуемо. |

## Ошибки и ограничения

Для получения ответов требуется интернет и действующие учётные данные GigaChat API.
Результат зависит от доступности внешнего API и полноты запроса пользователя.
При отсутствии обязательных данных агент не формирует ответ, а сообщает об ошибке ввода.
Секретные значения конфигурации в отчёт не включаются.
