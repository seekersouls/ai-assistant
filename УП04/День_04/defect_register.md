# Реестр дефектов

## BUG-01 — Добавление неподтверждённой информации

**Описание:** При психологическом анализе персонажей агент добавляет сведения и характеристики, которые отсутствуют в предоставленных данных.

**Шаги воспроизведения:**
1. Ввести запрос на анализ персонажа.
2. Указать ограничение «Не выдумывать информацию».
3. Запросить анализ характера, мотивации и слабых сторон.
4. Проверить полученный ответ.

**Ожидаемый результат:** Агент использует только предоставленную информацию. Отсутствующие сведения отмечает как «не указано».

**Фактический результат:** Агент добавляет неподтверждённые сведения и делает предположения о персонаже.

**Серьёзность:** Средняя.
**Причина:** Полностью исключить подобные предположения средствами промпта не удалось. Ограничение зафиксировано для дальнейшей доработки.

**Статус:** Отложен.

## BUG-02 — Ошибка при недоступности API

**Описание:** При проверке подключения с некорректными данными авторизации GigaChat возвращает ошибку.

**Шаги воспроизведения:**
1. Выполнить безопасную проверку с некорректной тестовой конфигурацией.
2. Попытаться отправить запрос агенту.
3. Зафиксировать сообщение об ошибке.

**Ожидаемый результат:** Агент сообщает о проблеме подключения понятным для пользователя сообщением.

**Фактический результат:** Возникает ошибка `400 BadRequestError: Can't decode 'Authorization' header`.

**Серьёзность:** Низкая (требуется проверить качество обработки ошибки).

**Статус:** Исправлен и перепроверен.
