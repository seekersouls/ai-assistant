# УП.04 — День 10. Диагностика и испытания ИИ-агента

## Цель работы

Проверить корректность конфигурации Docker Compose, работу Python и установленных зависимостей внутри образа, провести четыре испытания и зафиксировать обнаруженные ошибки и способы их устранения.

## Проверка ошибочной конфигурации YAML

Для проверки была создана временная копия основного файла:

```bash
cp compose.yaml compose.test.yaml
```

В тестовой копии значение `build: .` было заменено на `build: [ . ]`, то есть вместо строки был указан список.

Проверка тестовой конфигурации:

```bash
sudo docker compose -f compose.test.yaml config --quiet
```

**Фактический результат:** Compose отклонил ошибочную конфигурацию и сообщил, что `services.agent.build` должно быть строкой (`must be a string`).

После проверки временная копия была удалена:

```bash
rm compose.test.yaml
```

Основная конфигурация проверена повторно:

```bash
sudo docker compose config --quiet
```

Результат: основной файл `compose.yaml` прошёл проверку.

## Проверка Python и зависимостей

Проверка версии Python внутри образа:

```bash
sudo docker compose run --rm --no-deps --entrypoint python agent --version
```

Проверка зависимостей:

```bash
sudo docker compose run --rm --no-deps --entrypoint python agent -m pip check
```

**Фактический результат:** команда `pip check` вывела:

```text
No broken requirements found.
```

Конфликтов между установленными Python-зависимостями не обнаружено.

## Четыре приёмочных испытания

| № | Испытание | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| 1 | Основной запрос | Агент выполняет свою целевую задачу | Агент запустился и сформировал ответ на запрос о персонаже | Пройдено |
| 2 | Некорректный ввод | Программа корректно реагирует на пустой или неверный запрос | При отсутствии необходимых данных программа вывела сообщение: «Ошибка: необходимо указать данные персонажа» | Пройдено |

| 4 | Ошибка YAML | Неверная тестовая конфигурация отклоняется, основной файл проходит проверку | Тестовая копия отклонена с ошибкой типа `build`; основной `compose.yaml` прошёл проверку | Пройдено |

По результатам выполненных проверок критических конфликтов Python-зависимостей не обнаружено. Ошибочная тестовая конфигурация была отклонена, а исходный Compose-файл прошёл проверку.

## Завершение работы

```bash

```

```bash
sudo docker compose ps -a
```
