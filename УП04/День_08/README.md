# УП04 — День 8. Запуск и тестирование ИИ-агента в Docker

## 1. Запуск контейнера

Для запуска ИИ-агента использовалась команда:

```bash
sudo docker run -it --name my-ai-run --env-file .env my-ai-agent:1.0
```

Переменные окружения передаются через локальный файл `.env`.

Файл с секретными данными не копируется в Docker-образ и не публикуется в GitHub.

def clean_for_utf8(text):
    return "".join(
        "\uFFFD" if 0xD800 <= ord(char) <= 0xDFFF else char
        for char in text
    )


SYSTEM_PROMPT = clean_for_utf8(SYSTEM_PROMPT)
