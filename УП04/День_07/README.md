# УП04 — День 7. Контейнеризация ИИ-агента

## 1. Информация о проекте

Название проекта: ИИ-помощник по созданию и психологическому анализу персонажей.

Назначение: создание оригинальных персонажей и психологический анализ уже существующих персонажей.

Язык программирования: Python

Версия Python: 3.12.3

Используемый API: GigaChat API

## 2. Создание Dockerfile

Для контейнеризации проекта был создан файл `Dockerfile`

В нём используются следующие инструкции:

`FROM` — выбор базового образа Python.
`WORKDIR` — создание рабочей директории `/app`.
`ENV` — настройка вывода Python без задержки.
`COPY` — копирование файлов проекта.
`RUN` — установка необходимых библиотек.
`CMD` — запуск программы через `main.py`.

## 3. Настройка .dockerignore

Создан файл `.dockerignore`, исключающий ненужные и конфиденциальные файлы из контекста сборки

Исключены:

`.venv/`, `venv/` — виртуальные окружения
`.env`, `.env.*` — файлы с настройками и секретами
`.git/` — служебные файлы Git
`__pycache__/`, `*.pyc` — кэш Python
`*.log` — файлы журналов
`chat_history.txt` — история переписки
`last_answer.txt`, `last_prompt.txt` — временные файлы проекта
`*.pem`, `*.key` — файлы ключей и сертификатов

## 4. Сборка Docker-образа

Для сборки Docker-образа использовалась команда:

```bash
sudo docker build -t my-ai-agent:1.0 .
```

Имя образа: `my-ai-agent`

Тег: `1.0`

Результат сборки: Программа запустилась один раз, после приходится создавать новую или удалять прежднюю

## 5. Проверка Docker-образа

Для проверки использовались команды:

```bash
sudo docker images my-ai-agent
sudo docker run --rm --entrypoint python my-ai-agent:1.0 --version
```

**Результат проверки:** Проверка показала список в котором есть образ my-ai-agent с тегом 1.0. Python внутри образа вывел версию 3.12.16

## 6. Итог

В ходе выполнения Дня 7 была подготовлена конфигурация Docker для ИИ-агента. Созданы Dockerfile и .dockerignore, выполнена подготовка проекта к сборке и запуску в контейнере.
