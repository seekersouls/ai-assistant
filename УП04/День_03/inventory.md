# Инвентаризация ИИ-агента

## 1. Паспорт проекта

Название: ИИ-помощник по созданию и психологическому анализу персонажей.

Назначение: Создание оригинальных художественных персонажей и психологический анализ уже существующих персонажей.

Основные функции:
- Создание оригинальных персонажей.
- Психологический анализ персонажей.
- Анализ мотивации, страхов, эмоций и поведения.
- Анализ отношений между персонажами.
- Работа с различными литературными жанрами.
- Выбор краткого или подробного формата ответа.
- Сохранение последнего запроса и ответа в текстовые файлы.

Файл запуска: `main.py`.

Язык и версия Python: Python 3.8.13.

Дата проверки: 19.11.2026.

## 2. ИИ-компоненты

Модель и поставщик: GigaChat-2, Сбер.

API или локальная модель: Внешний GigaChat API.

Библиотека подключения: `gigachat`.

Файл вызова модели: `main.py`.

Промпты и инструменты:
 `prompts.py` — системный промпт `SYSTEM_PROMPT`, определяющий задачи и правила работы ИИ-помощника.
 `main.py` — получение пользовательского ввода, формирование запроса и отправка его модели.
 `last_prompt.txt` — сохранение последнего сформированного запроса.
 `last_answer.txt` — сохранение последнего полученного ответа.

Дополнительно используются настройки модели: температура генерации `0.2` и ограничение ответа `400` токенов.

## 5. Внешние сервисы и настройки

Внешний сервис: GigaChat API.

Поставщик: Сбер.

Используемая модель: GigaChat-2.

Настройки подключения:
 `GIGACHAT_CREDENTIALS` — учётные данные для подключения к API.
 `GIGACHAT_SCOPE` — область доступа к API.

Способ загрузки настроек: библиотека `python-dotenv` с использованием `load_dotenv()`

Способ получения переменных: `os.getenv()`

Сертификат: `certs/russian_trusted_root_ca_pem.crt`

Дополнительные параметры подключения: тайм-аут 60 секунд.

Сохранение результатов: последний запрос и ответ записываются в отдельные текстовые файлы.

База данных и отдельные локальные модели в проекте не используются.

## 6. Неустановленные сведения

Точное количество запросов, которое может обработать API за определённый период, не установлено.
Внутреннее устройство и ограничения внешнего GigaChat API не исследовались.
Отдельная база данных отсутствует.
Полноценное сохранение истории диалога не реализовано: сохраняются только последний запрос и последний ответ.

## 7. Проверка безопасности

Способ хранения настроек: учётные данные для подключения к GigaChat API хранятся в файле `.env` и загружаются через `python-dotenv`

Найденные проблемы:
 Файл `.env` содержит конфиденциальные настройки и не должен публиковаться в GitHub.
 Необходимо исключать виртуальное окружение и временные файлы из публикации.
 При использовании внешнего API работа зависит от доступности сервиса и действительности учётных данных.

Предпринятые действия:
 Создан файл `.gitignore` с правилами исключения `.env`, `.venv`, `venv`, `__pycache__`, файлов `.pyc` и других служебных данных
 Создан `.env.example` для примера настройки переменных окружения
 Настройки подключения загружаются из переменных окружения, а не указываются непосредственно в коде.
