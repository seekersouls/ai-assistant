## 5. Риски

Зависимость от внешнего API => при недоступности сервиса агент не сможет получать ответы => контролировать доступность GigaChat API.

Использование секретных данных => возможная утечка учётных данных => хранить ключи в .env и не публиковать их на GitHub.

Зависимость от сертификата => ошибка подключения при отсутствии сертификата => сохранять необходимый сертификат в папке certs/.

Недостоверность ответов ИИ => пользователь может получить ошибочную информацию о персонаже => улучшить системный промпт и предусмотреть проверку фактов.

Добавление неподтверждённых сведений => психологический анализ может содержать выдуманные характеристики => усилить ограничения на использование неизвестной информации.
