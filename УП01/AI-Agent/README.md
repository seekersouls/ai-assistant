# ИИ-помощник по созданию и психологическому анализу персонажей

## 1. Назначение проекта

Проект представляет собой ИИ-помощника для создания оригинальных художественных персонажей и психологического анализа уже существующих персонажей.

## 2. Основные возможности

- Создание оригинальных персонажей.
- Психологический анализ персонажей.
- Анализ мотивации, страхов и поведения.
- Анализ отношений между персонажами.
- Работа с различными литературными жанрами.
- Выбор краткого или подробного формата ответа.
- Сохранение последнего запроса и ответа в текстовые файлы.

## 3. Используемые технологии

- Язык программирования: Python.
- ИИ-модель: GigaChat-2.
- Поставщик модели: GigaChat (Сбер).
- API: GigaChat API.
- Библиотека подключения: gigachat.
- Загрузка настроек: python-dotenv.

## 4. Структура проекта

- `main.py` — основной файл запуска программы.
- `prompts.py` — системный промпт ИИ-помощника.
- `requirements.txt` — список необходимых библиотек.
- `.env.example` — пример файла с переменными окружения.
- `.env` — настройки подключения к API.
- `certs/` — папка с сертификатом для подключения к GigaChat.
- `last_prompt.txt` — последний сформированный запрос.
- `last_answer.txt` — последний полученный ответ.

## 5. Требования

- Python 3.
- Доступ к интернету.
- Учётные данные для подключения к GigaChat API.
- Установленные зависимости из requirements.txt.

## Запуск в Docker

Для запуска ИИ-агента используется Docker-контейнер.

### 1. Необходимая конфигурация

Перед запуском необходимо:
- Установить Docker.
- Убедиться, что в проекте присутствуют `Dockerfile` и `.dockerignore`.
- Проверить наличие `requirements.txt`.
- Создать локальный файл `.env` с необходимыми переменными окружения.
- Убедиться в наличии сертификата GigaChat по пути `certs/russian_trusted_root_ca_pem.crt`.

Переменные окружения:
- `GIGACHAT_CREDENTIALS` — данные авторизации GigaChat API.
- `GIGACHAT_SCOPE` — область доступа API.

Файл `.env` не включается в Docker-образ и не публикуется в GitHub.

### 2. Сборка Docker-образа

Из директории `УП01/AI-Agent` выполните команду:

```bash
sudo docker build -t my-ai-agent:1.0 .
```

### 3. Запуск контейнера

Для запуска ИИ-агента выполните:

```bash
sudo docker run -it --name my-ai-run --env-file .env my-ai-agent:1.0
```

### 4. Проверка контейнера

Для просмотра состояния контейнера используйте:

```bash
sudo docker ps -a
```

Для просмотра последних записей журнала:

```bash
sudo docker logs --tail 20 my-ai-run
```

### 5. Повторный запуск

Для повторного запуска остановленного контейнера используйте:

```bash
sudo docker start -ai my-ai-run
```

Если в проект были внесены изменения, необходимо пересобрать Docker-образ и создать новый контейнер.
