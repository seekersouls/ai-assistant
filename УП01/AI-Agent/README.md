# ИИ-помощник по созданию и психологическому анализу персонажей

## 1. Назначение проекта

Проект представляет собой ИИ-помощника для создания оригинальных художественных персонажей и психологического анализа уже существующих персонажей.

## 2. Основные возможности

- Создание оригинальных персонажей.
- Психологический анализ персонажей.
- Анализ мотивации, страхов и поведения.
- Анализ отношений между персонажами.
- Работа с различными литературными жанрами.
- Выбор краткого или подробного формата ответа.
- Сохранение последнего запроса и ответа в текстовые файлы.

## 3. Используемые технологии

- Язык программирования: Python.
- ИИ-модель: GigaChat-2.
- Поставщик модели: GigaChat (Сбер).
- API: GigaChat API.
- Библиотека подключения: gigachat.
- Загрузка настроек: python-dotenv.

## 4. Структура проекта

- `main.py` — основной файл запуска программы.
- `prompts.py` — системный промпт ИИ-помощника.
- `requirements.txt` — список необходимых библиотек.
- `.env.example` — пример файла с переменными окружения.
- `.env` — настройки подключения к API.
- `certs/` — папка с сертификатом для подключения к GigaChat.
- `last_prompt.txt` — последний сформированный запрос.
- `last_answer.txt` — последний полученный ответ.

## 5. Требования

- Python 3.
- Доступ к интернету.
- Учётные данные для подключения к GigaChat API.
- Установленные зависимости из requirements.txt.

## 6. Установка и настройка

Ссылка на репозиторий: https://github.com/seekersouls/ai-assistant/tree/main/%D0%A3%D0%9F01/AI-Agent

1. Переход в папку агента:
### Windows (PowerShell)

```powershell
cd .\УП01\AI-Agent
```

### Linux

```bash
cd УП01/AI-Agent
```

3. Создать виртуальное окружение.
### Windows (PowerShell)

```powershell
py -m venv .venv
```

### Linux

```bash
python3 -m venv .venv
```
   
4. Установить необходимые библиотеки из requirements.txt.
   
6. Создать файл `.env` на основе:
GIGACHAT_CREDENTIALS=
GIGACHAT_SCOPE=
   
8. Заполнить переменные GIGACHAT_CREDENTIALS и GIGACHAT_SCOPE.
   
9. Убедиться, что сертификат находится в папке `certs/`.
    


## 7. Запуск программы

### Windows (PowerShell)

Из папки AI-Agent:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

### Linux

Из папки AI-Agent:

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python main.py
```

## 8. Ограничения проекта

- Для получения ответов требуется подключение к интернету.
- Для работы необходимы действующие учётные данные GigaChat API.
- Работа программы зависит от доступности внешнего API.
- Качество ответов зависит от предоставленной информации и запроса пользователя.
